
# TikTok Growth Intelligence System — Beginner Guide

## 1. Introduction

This system helps plan, research, create, publish and improve TikTok content for two separate brands:

1. Travel Alerts.ke
2. Simo Traveller

Its purpose is to make content decisions more organised, consistent and evidence-led.

The system is designed to support growth, audience trust and long-term brand development.

## 2. Understanding the Repository

The repository contains different sections, each with a specific responsibility.

| Folder | Purpose |
|---|---|
| Agent | Instructions governing how the AI agent works |
| Algorithm | TikTok recommendation and search knowledge |
| Brands | Separate strategies and content resources for each brand |
| Research | Trends and competitor intelligence |
| Analytics | Performance records and reports |
| Experiments | Controlled tests to improve performance |
| Manual | Guides for operating the system |

Do not mix the identities or audiences of the two brands.

## 3. Choosing a Brand

Before starting a task, specify which brand the work is for.

### Travel Alerts.ke

Focus on:
- Breaking travel developments.
- Visa and immigration changes.
- Border and destination alerts.
- Airport and airline developments.
- Flight opportunities and discounts.
- Hotels and hospitality.
- African destinations and travel opportunities.

Prioritise current, verified and useful travel information.

### Simo Traveller

Focus on:
- African destinations.
- Wildlife and safari experiences.
- Hiking and outdoor activities.
- Hidden gems and scenic locations.
- Budget travel guides.
- Transport and accommodation.
- Travel stories and practical advice.

Never claim personal travel experience unless it is genuine.

## 4. Main Ways to Use the System

### A. Research

Ask the agent to identify current and relevant topics.

Specify:
- Brand.
- Geographic focus.
- Research period.
- Type of development or content.
- Any important restrictions.

For changing travel information, request official and primary sources.

### B. Content Planning

Ask the agent to recommend:
- Topics.
- Audience.
- Content pillar.
- Video angle.
- Hook.
- Format.
- Practical audience value.

### C. Video Production

Request:
- Opening hook.
- Voiceover script.
- Scene-by-scene visual direction.
- On-screen text.
- Caption.
- Search keywords.
- Relevant hashtags.
- Call to action.

### D. Performance Analysis

Provide available TikTok analytics.

Ask the agent to assess:
- Views.
- Average watch time.
- Completion rate.
- Shares.
- Saves.
- Comments.
- Profile visits.
- Followers gained.

The agent should explain what the data supports and what remains uncertain.

## 5. Standard Content Workflow

Use this sequence:

1. Select the brand.
2. Research the topic.
3. Verify important facts.
4. Evaluate audience relevance.
5. Select a content angle.
6. Write the script.
7. Prepare visuals and editing instructions.
8. Review accuracy and quality.
9. Publish when authorised.
10. Record performance.
11. Identify improvements.
12. Test promising changes.

Not every researched topic should become a video.

## 6. Using Research Properly

Always distinguish:
- Confirmed facts.
- Credible but developing information.
- Unverified claims.
- Editorial interpretation.

For travel alerts, check official government, immigration, aviation, airport and airline sources where relevant.

For destination guides, verify visitor requirements, fees, opening arrangements and transport information.

Record source links and the dates checked.

## 7. Understanding Performance

Do not judge a video by views alone.

Consider:
- Did viewers stay?
- Did they finish watching?
- Did they share or save it?
- Did they visit the profile?
- Did they follow the account?

Compare similar videos and evaluate each brand independently.

Do not assume one successful video proves a permanent winning formula.

## 8. Using the Experiment Log

When testing a new approach:

1. Write down the hypothesis.
2. Identify the main variable.
3. Define the success metric.
4. Publish the test content.
5. Record results.
6. Compare with similar content.
7. Decide whether to adopt, repeat, modify or reject the approach.

Keep a record of unsuccessful tests as well as successful ones.

## 9. Important Operating Rules

- Protect the separate identities of both brands.
- Prioritise audience value over posting volume.
- Never invent facts, prices, statistics or personal experiences.
- Avoid unnecessary repetition.
- Use current information for changing subjects.
- Do not present assumptions as confirmed facts.
- Do not publish without appropriate human approval.
- Treat performance data as evidence, not a guarantee of future results.

## 10. Getting Started

A new user can begin with five simple requests:

1. Research current content opportunities for Travel Alerts.ke.
2. Find an interesting African destination for Simo Traveller.
3. Create a complete TikTok video script for a selected topic.
4. Analyse the performance of a published video.
5. Recommend one experiment to improve future content.

## 11. Final Principle

The system is a decision-support and growth tool.

It should help produce better research, stronger content, more informed experiments and continuous improvement.

The objective is not simply to publish more videos.

It is to build two credible brands that attract and retain the right audiences.
